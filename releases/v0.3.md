BM Spectrum Android v0.3 adds built-in microphone calibration and recording-input controls.

- Calibrate the built-in microphone against an external reference in four sequential recordings. Each input gets 3 seconds of background-noise capture and the same repeated pink-noise signal. The signal has 0.2-second fades outside the analyzed periods.
- Store the latest successful correction with 1.0-octave smoothing, a ±20 dB limit and a validated frequency range. The calibration switch remembers your choice: correction and range restriction apply to the matching built-in microphone, while external inputs bypass correction.
- Inspect both noise spectra, both signal spectra, the correction and valid range. Diagnostic spectra include de-pink and microphone-level alignment. Landscape calibration places controls and instructions beside the graph.
- Select physical recording inputs under INPUT in Settings. Supported external microphones expose an input-gain slider that applies changes after editing, between recordings. USB gain control has been tested with ECM8000-U.
- Monitor input peaks with a narrow bar beside the main graph. Calibration errors identify low SNR, clipping and missing reference inputs.
- RTA includes the 512-point / 0.3-octave and 1024-point / 0.15-octave line presets; 1/12-octave mode uses bars.

Numerical tests and device checks cover calibration analysis, fades, background-noise averaging, storage, input switching and layout. Physical calibration was checked on V2529 with ECM8000-U and a Bluetooth speaker; validation across other hardware remains open. Calibration is relative frequency response, not calibrated SPL. See [the calibration guide](https://github.com/max-bold/SpectrumAndroid/blob/v0.3/CALIBRATION.md).

Install **BM-Spectrum-debug.apk** on Android 7.0 or later. This remains a development/debug build, signed by GitHub Actions with the established release key so it can update the ordinary BM Spectrum app. BM Spectrum Dev is a separate development installation. Verify the download with **SHA256SUMS.txt**.
