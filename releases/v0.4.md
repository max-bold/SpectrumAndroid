# BM Spectrum Android v0.4

- New microphone calibrations use 0.5-octave log-Gaussian smoothing instead of 1.0 octave to retain more of the built-in microphone's frequency-response detail.
- When a matching built-in microphone calibration is enabled, both Band sliders use its valid frequency range. Rounded slider values cannot exceed the calibration endpoints. Disabling calibration or selecting an external input restores the full 20–20000 Hz range.
- Existing calibration curves and settings are preserved. Repeat calibration to obtain a new curve with 0.5-octave smoothing.

The user confirmed normal calibration operation on the current setup. Broader validation on other devices remains open in TODO.md.

This APK updates the existing app without clearing data and uses the same development signing certificate as previous releases.
