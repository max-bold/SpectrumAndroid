BM Spectrum Android v0.2.1 improves live RTA responsiveness, USB audio compatibility and measurement controls.

- RTA analyzes the latest complete recording window when processing falls behind, skipping obsolete updates instead of building latency. The 1/12-octave mode is drawn as a line; 1/3 and 1/6 remain bars.
- The RTA cursor follows the current maximum and stays at the last measured maximum after stopping, including when a cursor had been selected manually before the run.
- Settings open immediately while the measurement finishes stopping. Spectrum smoothing now ranges from 0.1 to 1.0 octave; older saved values are clamped without discarding other settings.
- External USB audio interfaces have improved duplex playback support. On the tested V2529 and Creative SB X-Fi Surround 5.1 Pro, Android's supported 48 kHz stereo PCM16 mixer and USB capture with VOICE_RECOGNITION avoid the playback failure and low-frequency filtering observed with other paths. Other devices remain dependent on their Android audio drivers.
- Numerical tests cover RTA scale and de-pink, generator output, and a simulated analyzer that falls behind multiple hop intervals. Physical USB loopback checks verified the input and both generators; broader hardware compatibility is not guaranteed.

Install **BM-Spectrum-debug.apk** on Android 7.0 or later. This remains a development/debug build, signed with the same development key as previous releases so it can update an existing installation. Verify the download with **SHA256SUMS.txt**.
