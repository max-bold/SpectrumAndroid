BM Spectrum Android v0.2 improves Spectrum final analysis, generator envelopes and landscape settings.

- Online Welch is now a live preview; the final result always uses a periodogram of the full recording, including early stops.
- RTA uses a rectangular window with the generator enabled and Hann for external sound.
- Chirp adds 0.5 s fades outside the working sweep; its extended tail is kept below Nyquist at 48 kHz. Pink noise fades at session boundaries, without fading each repeated period.
- Welch window and hop are shown in seconds. Existing exact settings are preserved.
- Mode selection stays visible above scrollable settings in landscape. The graph logo is smaller, translucent and tinted.
- Numerical regression coverage includes final analysis, RTA windows, amplitude scaling and sweep extension. GitHub Actions builds, tests and publishes tagged releases.
- Large final smoothing plans are evaluated without retaining a huge coefficient matrix. A 30 s recording (1,440,000 samples) completed on the connected phone; its final analysis took about 4.3 s.

Validation: 12 numerical DSP tests and Android lint passed locally and on GitHub Actions. Device checks covered Welch-to-periodogram completion, early stop, generator lifecycle, cache reuse, cursor and settings scrolling in both landscape rotations.

Install **BM-Spectrum-debug.apk** (Android 7.0+). This remains a development/debug build, signed with the same development key as v0.1 so it can update that installation. SHA256SUMS.txt identifies the uploaded APK.

External-input and physical generator-output measurements are deferred until the required audio interface is available. Microphone calibration files and calibrated SPL are not implemented. See TODO.md for deferred work.
